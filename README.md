# PrioLock - canal de mises a jour

Ce depot ne contient que le canal de mises a jour de PrioLock :

- `latest.json` : le manifeste de la derniere version, **signe** (Ed25519) ;
- `latest.json.sig` : sa signature ;
- les releases `vX.Y.Z` : les installeurs.

PrioLock refuse toute mise a jour dont le manifeste n est pas signe par sa cle. Le code source n est pas publie ici.
